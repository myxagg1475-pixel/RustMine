# RustMine content progress

## Current prototype — Minecraft Java 1.21.1

Eight item model entries are included:

1. Scrap
2. Cloth bundle
3. Metal component
4. Wood bundle
5. Stone chunk
6. Water canister
7. Field backpack
8. Cloth hood

The models are cuboid prototypes and currently use vanilla Minecraft textures as placeholders. The resource-pack build validates JSON and packages a ZIP artifact.

## Not implemented yet

- Original RustMine pixel-art textures
- Registered Fabric items and gameplay integration
- Animated first-person item movement
- Wearable armor behavior and player equipment rendering

The first-person display settings only position static item models; they are not animations. Animation work requires the mod layer, not just these resource-pack JSON files.
